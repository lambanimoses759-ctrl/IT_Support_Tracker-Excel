# IT Support Tracker - Excel Dashboard

Excel IT helpdesk tracker with dashboard (COUNTIF, AVERAGE) - ALX Data Analytics project

## Simulates real IT helpdesk ticket tracking for a tech support team. Built as part of ALX Africa Data Analytics program.

### Dashboard KPIs
- Total Tickets: 20
- Open: 10 | Closed: 10
- High Priority Open: 4
- Avg Resolution Time: 0.86 Hours

### Skills Used
- Excel Formulas: COUNTA, COUNTIF, COUNTIFS, AVERAGE
- Data Cleaning: Standardized Priority, Category, Status
- Dashboard Design for IT Management
- Structured data ready for PivotTables

### Sheets
1. Tickets Log - 20 tickets (Hardware, Software, Network, Security)
2. Dashboard - Auto-calculated metrics

### Use Case
Daily work of an IT Technician Intern: logging issues, prioritizing, tracking resolution time, reporting to management.
